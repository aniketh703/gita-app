# ✅ 1) DATA SOURCES (Verse Content)

### 🟢 Bhagavad-Gita Datasets (Offline)

These are sources you can pull and convert to your **chapter JSON** format:

📌 **Bhagavad Gita Dataset on Kaggle**
Sanskrit + English + Hindi translations in CSV & JSON styles. ([Kaggle][1])
🔗 [https://www.kaggle.com/datasets/madhurpant/bhagavad-gita-verses-dataset](https://www.kaggle.com/datasets/madhurpant/bhagavad-gita-verses-dataset)

📌 **Parallel corpus (Hugging Face)**
Sanskrit with aligned English + Hindi updates. Good for transliteration work. ([Hugging Face][2])
🔗 [https://huggingface.co/datasets/JDhruv14/Bhagavad-Gita_Dataset](https://huggingface.co/datasets/JDhruv14/Bhagavad-Gita_Dataset)

📌 **Bhagwat-Gita-Infinity dataset** (JSON styled)
Has structured chapter/verse JSON — easy to adapt and convert. ([Hugging Face][3])
🔗 [https://huggingface.co/datasets/Modotte/Bhagwat-Gita-Infinity](https://huggingface.co/datasets/Modotte/Bhagwat-Gita-Infinity)

⚠️ **Important:**
Many datasets include **public domain text** (Sanskrit, older English translations), but some modern translations are copyrighted. Always verify usage terms before publishing in your app.

You *don’t* need these for offline v1; but good for testing, initial prototyping, or fallback.

# 📱 Application Specification — *Bhagavad Gita Reading App (v1)*

## 1. High-Level Statement

The application is an **offline-first, multilingual mobile reading app** that presents the **Bhagavad Gita** in a clean, calm, and distraction-free format, enabling users to read original Sanskrit verses along with transliteration, translations, and optional commentary on Android devices.

---

## 2. Intent & Purpose

### Primary Intent

To provide a **reliable, respectful, and accessible digital experience** for reading the Bhagavad Gita in its authentic form, without distractions, advertisements, or dependency on internet connectivity.

### Purpose

* Preserve the sanctity of the original text while making it accessible to modern users
* Support readers across **multiple Indian and global languages**
* Enable focused reading through thoughtful typography, layout, and offline availability
* Serve as a foundational platform for future spiritual engagement features

---

## 3. Target Users & Their Needs

### 3.1 Target User Groups

#### 1. Spiritual Seekers

* Want authentic Sanskrit verses
* Prefer calm, uncluttered UI
* Value offline access and readability

#### 2. Students & Learners

* Need transliteration to aid pronunciation
* Require clear translations
* Prefer chapter/verse structure

#### 3. Multilingual Indian Users

* Prefer reading in **Hindi, Tamil, or Kannada**
* Want culturally respectful presentation

#### 4. Casual Readers

* Want simple navigation
* Minimal setup
* Easy font and theme adjustments

---

### 3.2 User Needs Mapping

| User Need            | App Response                   |
| -------------------- | ------------------------------ |
| Read authentic Gita  | Public-domain Sanskrit text    |
| Understand verses    | Transliteration + translations |
| Language flexibility | 5-language support             |
| Focused reading      | Minimalist UI                  |
| Offline usage        | Bundled JSON + fonts           |
| Accessibility        | Font size control + dark mode  |

---

## 4. Core Features & Functionality (v1)

### 4.1 Reading & Content

* Chapter-wise organization (18 chapters)
* Verse-by-verse presentation
* Original Sanskrit shlokas (always visible)
* Transliteration (toggleable)
* Translations in:

  * English
  * Hindi
  * Tamil
  * Kannada
* Optional public-domain commentary (collapsible)

---

### 4.2 Personalization & Accessibility

* Global language selection
* Adjustable font size
* Light / Dark mode
* Script-appropriate fonts per language

---

### 4.3 Technical Characteristics

* Fully offline after installation
* No backend dependency
* No login or user accounts
* No ads
* No analytics tracking (v1)

---

### 4.4 Navigation & Screens

* Home Screen
* Chapters Screen
* Shloka Reading Screen
* Settings / Profile Screen

---

## 5. Developer-Ready Technical Specification

### 5.1 Platform & Framework Constraints

| Category   | Decision                    |
| ---------- | --------------------------- |
| Platform   | Android only (v1)           |
| Framework  | React Native (Expo managed) |
| Language   | TypeScript                  |
| Navigation | React Navigation            |
| State      | React Context               |
| Storage    | AsyncStorage                |
| Data       | Static JSON assets          |
| Backend    | None                        |

---

### 5.2 Offline Data Model (Canonical)

```json
{
  "chapter": 1,
  "verse_count": 47,
  "name": {
    "english": "Arjuna Vishada Yoga",
    "hindi": "अर्जुन विषाद योग",
    "tamil": "அர்ஜுன விஷாத யோகம்",
    "kannada": "ಅರ್ಜುನ ವಿಷಾದ ಯೋಗ"
  },
  "verses": [
    {
      "verse": 1,
      "sanskrit": "धर्मक्षेत्रे कुरुक्षेत्रे...",
      "transliteration": "dharmakshetre kurukshetre...",
      "translations": {
        "english": "...",
        "hindi": "...",
        "tamil": "...",
        "kannada": "..."
      },
      "commentary": {
        "english": "...",
        "hindi": "..."
      }
    }
  ]
}
```

**Rules**

* Sanskrit is mandatory
* Transliteration optional
* Commentary optional
* No network calls

---

### 5.3 UI / UX Constraints

* Minimalist, non-material design
* No excessive animations
* High contrast, readable typography
* Generous spacing for long verses
* Respectful spiritual tone

---

### 5.4 Fonts & Script Support

| Script                       | Font                  |
| ---------------------------- | --------------------- |
| Devanagari (Sanskrit, Hindi) | Noto Serif Devanagari |
| Tamil                        | Noto Serif Tamil      |
| Kannada                      | Noto Serif Kannada    |
| English                      | Merriweather          |

Fonts bundled locally.

---

### 5.5 Non-Functional Requirements

* App must function with **zero internet**
* Cold start < 2 seconds on mid-range Android devices
* Smooth scrolling for long chapters
* No crashes due to missing translations
* Play Store policy compliant

---

## 6. Explicit Out-of-Scope (v1)

The following are **intentionally excluded** to ensure timely delivery:

* Daily reading plans
* Streaks or heatmaps
* Shareable verse images
* Audio chanting
* User accounts
* Cloud sync
* Notifications

These are planned for post-launch iterations.

---

## 7. Success Criteria (v1)

* App approved on Google Play Store
* Reads correctly in all 5 languages
* No internet required after install
* Positive early feedback on readability and calm UI
* Stable performance across devices

---

## 8. Future-Ready Notes

The current architecture supports:

* Adding daily readings without schema change
* Adding bookmarks & streaks
* Adding verse card generation
* Adding commentary sources via attribution
